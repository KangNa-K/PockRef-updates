# PockRef updates — compatibility archive

PockRef updates have moved into the public source project:

**[Download PockRef and view releases](https://github.com/KangNa-K/PockRef/releases/latest)**

Source, APKs, release notes, issue reports and the current update manifest are
now maintained in [KangNa-K/PockRef](https://github.com/KangNa-K/PockRef).
Historical releases have been retained for existing links.

This repository is kept read-only for older installed versions (2.2.7–2.5.2).
Its final release, **2.5.3**, is a signed migration build identical to the one
in the main project. Upgrade to it once; all subsequent version checks and
downloads use the public PockRef project. Do not delete this compatibility
manifest or its APK assets while older installations may still use them.

No future versions will be published here.
